# De Paula — Site Premium

Landing page institucional responsiva com simulador de economia tributária.

## Rodar localmente
Abra o arquivo `index.html` no navegador ou use um servidor local:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Publicação
O projeto é compatível com GitHub Pages, Netlify e Vercel.

> Conteúdo demonstrativo. Revise textos jurídicos, marcas, contatos e identidade visual antes da publicação oficial.
